# Web Browsing

## Procedure

1. **Confirm the target.** Use the exact URL the user gave. If they named a site without a URL, browse the most obvious page (root or the one their wording points to).
2. **Extract, don't editorialize.** Report what the page actually says. Mark anything you infer as inference.
3. **Summarize to purpose.** If the user wants "the gist", give 3–5 bullets. If they want detail on X, go deep on X only.

## Rules

- State the page title and source so the user knows what was read.
- If content is missing, paywalled, or empty, say so plainly and offer the search tool as fallback.
- Never present stale or simulated page content as live-fetched without noting the limitation.

## Anti-patterns

- Browsing as a substitute for searching when no URL was given.
- Quoting large blocks verbatim instead of distilling.
- Guessing at page contents that failed to load.
