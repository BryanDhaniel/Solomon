# How to Research

## Procedure

1. **Clarify the question.** Restate what the user actually needs to know in one line. If their ask is broad ("research AI agents"), pick the 2–3 sub-questions that answer it.
2. **Search narrowly first.** Run one specific query, not a broad one. "AI agent frameworks 2026 comparison" beats "AI agents".
3. **Read before citing.** Only state facts backed by a search result snippet. Never invent numbers, dates, or names.
4. **Iterate once.** If results are weak, rephrase with more specific terms or add a year/qualifier. Do not spiral into many searches.

## Reporting rules

- Lead with the answer, not the process ("Here's the landscape:" not "I ran 3 searches").
- Group findings under short bold headings; one idea per bullet.
- Cite every non-obvious claim with its source URL inline.
- End with the single most useful next step for the user.

## Anti-patterns

- Dumping raw search results as a link list.
- Presenting a single source's marketing claim as fact.
- Researching tangents the user didn't ask about.
